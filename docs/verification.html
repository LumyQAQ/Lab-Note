本机验证

将文件放在同一目录，在该目录执行：

ssh-keygen -Y verify -f allowed_signers -I LumyQAQ -n lab-note-release -s lab-note-v1.0.zip.sig < lab-note-v1.0.zip

退出码为 0 表示签名有效。修改 ZIP 中的署名或其他内容后，原签名校验会失败。
