验证官方下载包

软件作者 LumyQAQ。请从官方仓库核对公钥，并选取与你下载的 ZIP 相同版本的签名。

Windows x64 预览版

1.7.0-preview.1 · 程序 ZIP · 发布签名 · SHA-256 摘要 · 公钥

在 PowerShell 中查看散列值，与本版本的 SHA-256 摘要比较：

Get-FileHash -Algorithm SHA256 .\Lab-Note-1.7.0-preview.1-Windows-x64.zip

签名验证请在支持 SSH 签名的命令提示符（cmd.exe）中执行：

ssh-keygen -Y verify -f allowed_signers -I LumyQAQ -n lab-note-release -s Lab-Note-1.7.0-preview.1-Windows-x64.zip.sig < Lab-Note-1.7.0-preview.1-Windows-x64.zip

macOS 正式版

1.7.0 · 程序 ZIP · 发布签名 · SHA-256 摘要 · 公钥

ssh-keygen -Y verify -f allowed_signers -I LumyQAQ -n lab-note-release -s lab-note-v1.7.0.zip.sig < lab-note-v1.7.0.zip

这两个版本使用同一把发布公钥，指纹为 SHA256:RCyT74zgnkYtwaYpZoZAs3Uo0JhbyaeajnID3seH4hU。验签命令退出码为 0 表示通过。
