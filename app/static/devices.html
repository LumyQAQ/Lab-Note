配置 Tailscale
  1. 在电脑上安装 Tailscale：打开 tailscale.com/download，选取 macOS 或 Windows 版本，安装后登录。
  2. 在手机 / 平板上安装 Tailscale：在 iPhone / iPad App Store 或安卓应用市场安装 Tailscale，登录同一个账号并打开开关。
  3. 回到本页点「刷新地址」：下方下拉框会自动出现 100.x.y.z · Tailscale 跨网直连，选中它并开启共享，扫码配对后即可通过此网络访问电脑上的记录。

首次连接与添加到主屏幕

1. 将下方公用证书发送到自己的手机或平板，核对此页的 SHA-256 指纹后安装并信任。
2. 用浏览器（iPhone / iPad 用 Safari，安卓用 Chrome / Edge）打开上方地址并输入 8 位配对码。
3. 配对成功后，可将 Lab Note 添加到主屏幕。

下载工作台证书 (.cer)
iPhone / iPad 与安卓详细步骤

iPhone / iPad 证书信任：收到证书后进入「设置 → 已下载描述文件」点击安装，再前往「设置 → 通用 → 关于本机 → 证书信任设置」，开启对应 Lab Note 证书的完全信任。

iPhone / iPad 添加为桌面 App：在 Safari 打开并完成配对后，点底部「分享」图标 → 选择「添加到主屏幕」，桌面即出现 Lab Note 独立图标。

安卓：在系统设置搜索「安装 CA 证书」选择收到的文件；在 Chrome/Edge 完成配对后，点右上角菜单选择「安装应用 / 添加到主屏幕」。
